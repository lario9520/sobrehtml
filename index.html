1. O que é a estrutura HTML?

Todo documento HTML possui uma estrutura básica. Essa estrutura ajuda o navegador a entender como o conteúdo da página deve ser interpretado e organizado.

💡 Imagine uma página HTML como uma casa.

A estrutura HTML funciona como a planta da casa: cada parte possui uma função específica.

Ela indica onde começa e termina o documento.

O que significa lang="pt-BR"?

O atributo lang="pt-BR" informa que o idioma principal da página é português do Brasil.

3️⃣

A tag contém informações sobre a página que normalmente não aparecem diretamente no conteúdo principal da tela.

Dentro do podemos colocar informações como:

  • Título da página
  • Configuração de caracteres
  • Configuração para dispositivos móveis
  • Arquivos CSS
  • Outras informações importantes
