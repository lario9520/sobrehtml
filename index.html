🌐 O que é HTML?

Entenda de forma simples o que é HTML e para que ele serve.

1. O que é HTML?

HTML significa HyperText Markup Language, que em português significa Linguagem de Marcação de Hipertexto.

O HTML é uma das principais tecnologias utilizadas para criar e organizar páginas da internet.

💡 Em palavras simples:
HTML é responsável por organizar o conteúdo de uma página, dizendo ao navegador onde ficam os títulos, textos, imagens, links, listas, botões e outros elementos.

2. Para que serve o HTML?

O HTML serve principalmente para definir a estrutura e o conteúdo de uma página.

Por exemplo, podemos usar HTML para criar:

  • 📌 Títulos
  • 📝 Textos e parágrafos
  • 🖼️ Imagens
  • 🔗 Links
  • 📋 Listas
  • 🔘 Botões
  • 📦 Seções de conteúdo
  • 📄 Formulários

8. HTML, CSS e JavaScript

Em uma página moderna, normalmente HTML, CSS e JavaScript trabalham juntos.

🧱 HTML → cria e organiza a estrutura.

🎨 CSS → modifica a aparência e o estilo.

⚙️ JavaScript → adiciona comportamento e interatividade.

Exemplo para memorizar:

Imagine uma casa:

🧱 HTML = estrutura da casa

🎨 CSS = pintura e decoração

⚙️ JavaScript = sistemas que fazem as coisas funcionarem
